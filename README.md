# HR Analytics Dashboard – Power BI

## 📌 Project Overview
This project is an **HR Analytics Dashboard** created using **Microsoft Power BI** to help HR teams and decision-makers analyze employee trends, compensation, job roles, and organizational demographics.  
It presents a clean, interactive, and visually professional view of the HR dataset, allowing users to explore workforce insights with ease.

The dashboard uses **Drillthrough** pages and **custom tooltips** to provide deeper insights into specific employee groups.

---

## 🚀 Key Features

### ✔ Interactive Visuals
- Total Employee Count  
- Monthly Income, Daily Rate, Hourly Rate KPIs  
- Department-wise employee count  
- Employee distribution by Job Role  
- Education Field analysis  
- Gender ratio  
- Age Group segmentation  
- Work-Life Balance gauge indicator  

### ✔ Advanced Power BI Features
- **Drillthrough** (for detailed employee-level reports)
- **Custom Tooltips** (hover insights)
- **Slicers** for:
  - Business Travel  
  - Overtime  
  - Attrition  
  - Gender  

### ✔ Visual Types Used
- Donut charts  
- Bar charts  
- Stacked charts  
- Treemap  
- KPI cards  
- Gauge charts  

---

## 📂 Pages Included
1. **Employee Overview Dashboard** (Main Page)  
2. **Job Role Analysis** (Drillthrough Page)  
3. **Department Insights** (Drillthrough Page)  
4. **Tooltip Pages** (For dynamic hover-based insights)
